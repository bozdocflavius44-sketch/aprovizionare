# Centralizator Aprovizionare

Aplicație web pentru comenzile săptămânale de marfă, pe furnizori.
Un singur fișier (`index.html`), fără dependențe, funcționează și offline.

Datele se salvează în browserul fiecărui dispozitiv și, opțional, se
sincronizează printr-un Google Sheet (Apps Script Web App). Adresa și
parola de sincronizare se introduc manual în aplicație, pe fiecare
dispozitiv — nu sunt scrise nicăieri în acest cod.
